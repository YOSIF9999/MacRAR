## ✨ What is MacRAR?

MacRAR is a native AppKit application built around RARLAB rar/unrar and 7-Zip 7zz. It gives you a simple window to open archives, extract files, and create new archives. You do not need to use Terminal or type commands. If you have ever used WinRAR on Windows, MacRAR feels familiar. It handles common archive formats and advanced features like password protection and split archives.

## 🖱️ How to Use MacRAR

Using MacRAR is simple. Follow these steps:

1. **Open an archive:** Double-click an archive file, or open MacRAR and click the Open button. Choose the archive you want to view.
2. **Extract files:** Select the files you want, then click Extract. Choose where to save the files.
3. **Create an archive:** Click New Archive. Select the files or folders you want to include. Choose a format (RAR, 7z, ZIP, or TAR) and click Create.
4. **Use Finder Quick Actions:** In Finder, right-click an archive file. Look for the MacRAR Quick Action menu. You can extract the archive or open it in MacRAR.
5. **Work with passwords:** When you open an encrypted archive, MacRAR asks for the password. When you create an archive, you can add a password in the settings.
6. **Handle multi-volume archives:** Open the first part of the archive (for example, `.part1.rar`). MacRAR automatically finds the other parts.

## 🔧 Troubleshooting

- **MacRAR does not open:** Make sure you moved the app to your Applications folder. If macOS says the app is from an unidentified developer, right-click the app and choose Open. Then click Open in the dialog.
- **Archive will not extract:** Check that the archive is not damaged. Try downloading the archive again. If the archive is encrypted, make sure you have the correct password.
- **Finder Quick Actions are missing:** Open MacRAR and go to Settings. Make sure Finder Quick Actions are turned on. You may need to restart Finder.
- **Multi-volume archive fails:** Make sure all parts of the archive are in the same folder. Open the first part, not the middle or last part.
- **App is slow with large archives:** Large archives need more memory and time. Close other apps and try again.
